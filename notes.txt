## Phase 1 — Data pipeline (E)

This is the foundation everything else pulls from. Start locally before touching Azure.

Download the [Kaggle Credit Card Fraud dataset](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud) and a stock price CSV from Yahoo Finance (`yfinance` library). Write a single Python script `pipeline/feature_engineering.py` that reads raw CSV, drops nulls, normalizes the `Amount` column with z-score, adds a `velocity_24h` rolling feature, and writes the result to a `data/staged/` folder. Once this works locally, you replicate it as a PySpark notebook in Databricks — the logic is identical, just swap pandas for spark DataFrames.

Only after local validation do you set up Azure Data Factory to pull from Blob Storage on a schedule. The staged output lands in your Fabric Lakehouse as a Delta table named `transactions_staged`.

```python
# ml/feature_engineering.py — start here, run locally
import pandas as pd

df = pd.read_csv("data/raw/creditcard.csv")
df = df.dropna()
df["amount_zscore"] = (df["Amount"] - df["Amount"].mean()) / df["Amount"].std()
df["velocity_24h"] = df.groupby("Time")["Amount"].transform(
    lambda x: x.rolling(window=24, min_periods=1).sum()
)
df.to_csv("data/staged/transactions_staged.csv", index=False)
```

## Phase 2 — Machine learning (B)

Work in `ml/fraud_classifier.ipynb`. The pipeline is: load staged CSV → train/test split (80/20, stratified on `Class`) → fit XGBoost → print AUC-ROC, precision, recall, F1 → `pickle.dump` the model to `ml/models/fraud_model.pkl` → export to ONNX.

```python
import xgboost as xgb
import pickle
from sklearn.model_selection import train_test_split
from sklearn.metrics import roc_auc_score

df = pd.read_csv("data/staged/transactions_staged.csv")
features = ["amount_zscore", "velocity_24h", "V1", "V2", "V3"]  # add more V cols
X, y = df[features], df["Class"]

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, stratify=y)
model = xgb.XGBClassifier(scale_pos_weight=577, eval_metric="auc")
model.fit(X_train, y_train)

print(f"AUC-ROC: {roc_auc_score(y_test, model.predict_proba(X_test)[:,1]):.4f}")
with open("ml/models/fraud_model.pkl", "wb") as f:
    pickle.dump(model, f)
```

Do Prophet forecasting in a separate notebook `ml/portfolio_forecast.ipynb`. Use `yfinance` to pull HDFC/INFY price history, fit Prophet, call `model.make_future_dataframe(periods=30)`, and save the forecast CSV.

## Phase 3 — FastAPI backend (A)

Create `backend/main.py`. Add all four endpoints with Pydantic models for request validation, structured `logging`, and try/except around every DB or model call. Start with in-memory/SQLite storage — swap to Azure SQL later.

```python
from fastapi import FastAPI
from pydantic import BaseModel
import pickle, logging

app = FastAPI()
logger = logging.getLogger(__name__)

with open("ml/models/fraud_model.pkl", "rb") as f:
    model = pickle.load(f)

class PredictRequest(BaseModel):
    amount_zscore: float
    velocity_24h: float
    v1: float

@app.post("/predict")
def predict(req: PredictRequest):
    try:
        features = [[req.amount_zscore, req.velocity_24h, req.v1]]
        score = model.predict_proba(features)[0][1]
        return {"fraud_score": round(score, 4), "label": int(score > 0.5)}
    except Exception as e:
        logger.error(f"Predict failed: {e}")
        raise
```

Write one `pytest` test immediately — before moving on:

```python
# tests/test_predict.py
from fastapi.testclient import TestClient
from backend.main import app

client = TestClient(app)

def test_predict_returns_score():
    r = client.post("/predict", json={"amount_zscore": 1.2, "velocity_24h": 50.0, "v1": -1.3})
    assert r.status_code == 200
    assert 0 <= r.json()["fraud_score"] <= 1
```

## Phase 4 — Agents (C)

Build agents one at a time in `agents/`. Start with the simplest: the ML expert agent. It just takes a fraud score and explains it using a system prompt with few-shot examples.

```python
from langchain_openai import AzureChatOpenAI

llm = AzureChatOpenAI(azure_deployment="gpt-4o", api_version="2024-02-01")

def explain_fraud_score(score: float, features: dict) -> str:
    prompt = f"""You are an ML expert. A transaction scored {score:.2f} (fraud probability).
    
Features: {features}

Explain in 2-3 sentences why this score is high or low, referencing the specific feature values.
Few-shot example:
Score 0.92: "This transaction scored very high due to an amount_zscore of 4.1 (far above normal)
and velocity_24h of 1200 (12x the average), indicating rapid unusual activity."
"""
    return llm.invoke(prompt).content
```

Then build the document assistant (RAG). Index your regulatory PDFs into FAISS locally first, then swap to Azure Cognitive Search:

```python
from langchain_community.vectorstores import FAISS
from langchain_openai import AzureOpenAIEmbeddings
from langchain.text_splitter import RecursiveCharacterTextSplitter
from langchain_community.document_loaders import PyPDFLoader

loader = PyPDFLoader("data/docs/sebi_aif_guidelines.pdf")
docs = loader.load()
splitter = RecursiveCharacterTextSplitter(chunk_size=1000, chunk_overlap=100)
chunks = splitter.split_documents(docs)
vectorstore = FAISS.from_documents(chunks, AzureOpenAIEmbeddings())
vectorstore.save_local("data/vectorstore")
```

Wire all three agents through an orchestrator that uses intent detection to route:

```python
def route_query(question: str) -> str:
    if any(w in question.lower() for w in ["sql", "average", "count", "last week"]):
        return sql_agent.run(question)
    elif any(w in question.lower() for w in ["sebi", "regulation", "compliance", "basel"]):
        return rag_agent.run(question)
    else:
        return ml_expert_agent.run(question)
```

## Phase 5 — Swap in Azure services (D)

1. Provision Azure OpenAI and swap the `AzureChatOpenAI` credentials from `.env`

```python

from azure.keyvault.secrets import SecretClient

credential = DefaultAzureCredential()
```

## The one rule that will save you

**Never move to the next phase until data actually flows through the current one.** Specifically: run your feature engineering script and verify the output CSV looks right before training. Train the model and verify `pickle.load` works before building the API. Call `/predict` with `curl` and get a real score back before building agents. This linear verification catches environment issues early when they're cheap to fix.
